# Prediction Outputs & Benchmark Verification

This directory contains sequence-level prediction outputs on the independent test set ($N = 386$ peptides) for both tasks, enabling instant verification of all published performance claims without running deep learning training or inference.

---

## 1. Classification Predictions (`classification_test_predictions_n386.csv`)

Contains predictions generated by the 5-fold ensemble of HLPpred 2.0:
* `sequence_id`: Sequence identifier (`Positive_1` to `Positive_179`, `Negative_1` to `Negative_207`)
* `sequence`: Peptide primary amino acid sequence
* `true_label`: Ground truth binary label ($1$ for hemolytic, $0$ for non-hemolytic)
* `predicted_class`: Model prediction (`Hemolytic` or `Non-Hemolytic` at default threshold $0.5$)
* `hemolytic_probability`: Ensemble predicted probability of hemolytic activity

### Metric Verification
Evaluating these 386 predictions yields:
* **Accuracy:** $88.34\%$ (341 / 386 correct)
* **Sensitivity (Sn):** $86.59\%$ (155 / 179)
* **Specificity (Sp):** $89.86\%$ (186 / 207)
* **MCC:** $0.7654$
* **AUC-ROC:** $0.9546$

---

## 2. Regression Predictions (`regression_test_predictions_n386.csv`)

Contains quantitative potency predictions:
* `sequence_id`: Sequence identifier
* `sequence`: Peptide primary amino acid sequence
* `true_HC50_uM`: Experimental $\text{HC}_{50}$ ($\mu\text{M}$)
* `true_pHC50`: Experimental $-\log_{10}(\text{Molar})$ potency
* `predicted_pHC50`: Ensemble predicted $\text{p}\text{HC}_{50}$
* `predicted_HC50_uM`: Transformed predicted $\text{HC}_{50}$ ($\mu\text{M}$)

### Metric Verification
Evaluating these 386 predictions yields:
* **$R^2$ (Coefficient of Determination):** $0.5939$
* **RMSE:** $0.4057$
* **MAE:** $0.3003$
* **Pearson Correlation ($R$):** $0.7717$ ($P = 1.73 \times 10^{-77}$)

---

## 3. External Tool Benchmarks
* **`classification_external_tools_benchmark.csv`**: Comparison across 12 predictors (HLPpred 2.0, HemoPI, HemoPI-2, HemoPred, HemoNet, Transformer-CNN, PeptideBERT, peptide-dashboard, HEPAD, AMPDeep, HLPpred-Fuse) including 95% bootstrap confidence intervals and paired permutation $P$-values.
* **`regression_external_tools_benchmark.csv`**: Head-to-head comparison against HemoPI-2 on the standardized $\text{p}\text{HC}_{50}$ scale with paired bootstrap testing ($P = 0.0326$ on RMSE).
